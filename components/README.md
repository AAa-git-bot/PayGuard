# components (담당: 최서은)

- `components/ui/` : shadcn/ui 기본 컴포넌트 (button, card, badge, tabs, dialog, table, input, textarea, label 설치됨)
- 화면별 컴포넌트는 이 폴더에 만든다. 예: `Timeline.tsx`, `SettlementTable.tsx`, `IssueCard.tsx`, `EvidencePanel.tsx`, `AiBadge.tsx`, `SourceModal.tsx`, `ChatRoom.tsx`, `TermsCard.tsx`
- 컴포넌트 추가: `npx shadcn@latest add <이름>`
